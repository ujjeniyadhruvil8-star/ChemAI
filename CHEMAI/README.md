# AI Chemistry Analyzer 🔬

An advanced Chemical Reaction Calculator & Compound Details Encyclopedia designed with textbook-grade rigor and responsive full-width layout.

## Features
- **Periodic Table Calculator**:
  - Full-width 18-column responsive periodic table.
  - Multi-reactant reaction builder: left-click to add, right-click to decrease count.
  - **Textbook-Style Reaction Output**: Stacked reference cards detailing:
    1. **Balanced Chemical Equation** (Purple box)
    2. **Reactants** (Cyan box)
    3. **Products** (Emerald box)
    4. **Reaction Type** (Violet box)
    5. **Energy Change / Enthalpy ΔH** (Amber box)
    6. **Molar Masses** (Deep Blue box)
    7. **Reaction Conditions & Mechanisms** (Yellow box)
    8. **Observable Visual Changes** (Indigo box)
    9. **Safety & Hazard Warnings** (Red box)
    10. **Real-World Applications** (Sky Blue box)

- **Compound Details**:
  - Comprehensive database search by formula or chemical name (`HBr`, `H2O`, `NaCl`, `CO2`, etc.).
  - Deep textbook breakdowns of molecular geometry, chemical bonding, reactions, and precautions.

## Running Locally

```bash
npm run dev
```
